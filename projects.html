Projects

A selection of research and engineering projects I've built or contributed to. Code for most of them lives on GitHub.

MAASH: Context Guard

A prompt-engineering-based context guard that generates targeted suggestions to restore essential project context during interactions with large language models. I fine-tuned a model to produce context-aware recovery prompts for development workflows across different AI models, helping maintain continuity during extended sessions.

Prompt Engineering Instruction Fine-Tuning NLP Context Management

Super Resolution for Satellite Images using ESRGAN

A super resolution model built on an Enhanced Super-Resolution Generative Adversarial Network, improving image clarity for remote sensing applications. It achieved higher efficiency than CNN-based super resolution models, making it practical for satellite and remote sensing use cases.

Python 3 PyTorch NumPy Remote Sensing

Decentralized Research Gap Resolution DApp

A decentralized bounty platform for resolving research gaps, combining distributed web-scraping-based originality verification with blockchain consensus. I implemented task creation, cryptographically signed solution submissions, majority-based validation, and transparent on-chain bounty distribution. Winner of the Sustainability Track at IIT Bombay Techfest 2025.

Rust Anchor Solana / K2 React.js IPFS

Predicting Crop Yield in India using Machine Learning

A comparative analysis of predictive models to find the best crop yield prediction approach, using a dataset spanning annual rainfall, fertilizer usage, pesticide application, geographical state, crop type, and seasonal attributes.
